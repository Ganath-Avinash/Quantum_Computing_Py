# Quantum Computing - Python - Qiskit
Qubits &amp; Me

This repository contains my Quantum Computing Py problems, implemented using Python and Qiskit.

## Contents

- Python programs for Quantum Computing problems using Qiskit
- Quantum circuit creation and visualization
- Basic quantum gates such as X, H, and CNOT
- Bell State construction
- Qubit measurement and analysis
- Quantum circuit simulation using Aer Simulator
- Comparison of classical bits and quantum bits
- PDF document containing the workshop problems, aims, programs, and outputs

## Technologies Used

- Python
- Qiskit
- Qiskit Aer
